PROJECT INFORMATION

Fake News Detection

Machine Learning Based News Classification using Natural Language Processing and Logistic Regression.

Project Overview

Fake News Detection is a machine learning based system developed to classify news articles as Real News or Fake News.

The system uses Natural Language Processing to preprocess news content and TF-IDF to convert textual information into numerical features. A Logistic Regression classification model is then used to perform the final classification.

The application provides a simple web interface where users can enter a news article and view the predicted class along with the model confidence. Prediction results are stored in a SQLite database for history and dashboard analysis.

Project Objective

  • Classify news articles as real or fake using Machine Learning.
  • Apply Natural Language Processing for text preprocessing.
  • Extract meaningful text features using TF-IDF.
  • Provide prediction confidence through the web application.
  • Maintain prediction history using SQLite.
  • Present analysis and model performance through a dashboard.

Machine Learning Model

The system uses Logistic Regression as the classification algorithm. The model is trained using the ISOT Fake News Dataset after converting news text into TF-IDF features.

Algorithm Logistic Regression
Feature Extraction TF-IDF
Classification Binary Classification

Model Performance

The following values are obtained from the held-out test dataset used during model evaluation.

Accuracy 99.28%
Precision 99.12%
Recall 99.37%
F1-Score 99.24%

Dataset

The system is trained using the ISOT Fake News Dataset, containing separate collections of fake and real news articles.

44,898 Total Articles
23,481 Fake Articles
21,417 Real Articles
50,000 Maximum TF-IDF Features

This system provides machine learning based classification of news text. A prediction should not be considered independent verification of the factual accuracy of an article.
