Project Overview

Fake News Detection is a machine learning based system developed to classify news articles as Real News or Fake News.

The system uses Natural Language Processing to preprocess news content and TF-IDF to convert textual information into numerical features. The selected model is then used to make a binary classification.

The application provides a simple web interface where users can enter a news article and view the predicted class along with the model confidence. Prediction results are stored in a SQLite database for history and dashboard analysis.

Project Objective

  • Classify news articles as real or fake using Machine Learning.
  • Apply Natural Language Processing for text preprocessing.
  • Extract meaningful text features using TF-IDF.
  • Provide prediction confidence through the web application.
  • Maintain prediction history using SQLite.
  • Present analysis and model performance through a dashboard.

Machine Learning Model

The system selects a classifier using group-aware validation macro F1, then evaluates it on a separate held-out test split. The training module compares Logistic Regression, Linear SVM, Passive-Aggressive, and Multinomial Naive Bayes. Random Forest is available as an optional comparison.
